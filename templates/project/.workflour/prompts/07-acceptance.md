# 给协调者和用户：验收

先读完整持久交接与阶段材料，核对当前实现快照、独立审查、真实测试和文档证据。逐条把 requirements 对应到具体验收结果，写 acceptance.md；未满足项写清原因，退回相应阶段。

运行 `python3 .workflour/check.py check --stage acceptance`，成功只表示材料与技术证据符合约定。准备一份简短、可检查的结果供用户验收。没有明确用户确认时停在 acceptance / pending。

用户确实确认后，记录来源、原话和带时区时间，再改 done。检查器不会证明人的授权；不得伪造确认或把模型自己的判断当作用户决定。用户要求的发布、部署或推送须按其实际授权另行执行。
