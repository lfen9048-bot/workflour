# 给 Coder：方案和任务

请先读 AGENTS、PROJECT-WORKFLOW、handoff，以及当前 feature 的 spec.md。只处理 handoff 指定任务。

先检索适合复用的已有实现，再用官方 setup-plan.sh 和 setup-tasks.sh 建立 plan.md、tasks.md，填写技术选择、依赖、执行顺序、需求对应关系、改动文件范围、必要测试和明确完成条件。替换所有占位示例，不把未经确认的范围变更写成要求。

运行官方 prerequisite helper，核对材料能找到；这不等于计划已获用户或独立审查认可。更新交接、下一步和代码写入范围，此轮不自行启动其他 Agent。
