# 给协调者：需求与验收定义

请先读 `AGENTS.md`、`PROJECT-WORKFLOW.md` 和 `.workflour/handoff.json`。本轮任务：`替换任务编号`；实际用户需求：`填写用户需求及已有确认来源`。

使用官方 create-new-feature.sh 创建 feature，将用户目标、需求编号、范围、非目标和可实际验证的验收条件写入 spec.md。明确区分用户已确认、助手建议和假设，实际技术栈留到 plan。已有记录能回答的事不要重复询问。

更新 handoff 的真实路径、requirements、负责人和下一步，生成 HANDOFF.md。尚不写产品实现，不调用另一个 Agent 或自动 headless。结束说明是否准备交给 Coder、仍缺什么。
