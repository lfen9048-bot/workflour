# 演练样例

仓库只发布 `plan-code-web-demo/index.html`、产品测试和使用说明，作为真实 Plan/Code 流程交付的代码样例。它是“今日三件事”单文件网页，不需要后端。

本机项目账本、Bot UUID、原始聊天和运行中状态未上传，不能直接把样例当作新电脑已经完成的团队任务。网页的独立技术审核、体验检查和截图摘要见 [验证材料](../docs/evidence/2026-11-11/README.md)。

部署新电脑时，创建一个全新的项目目录和任务，按 [Windows 验收步骤](../docs/windows-deployment/06-验收与故障排查.md) 重新跑通；不要复制 Mac 的任务状态。
