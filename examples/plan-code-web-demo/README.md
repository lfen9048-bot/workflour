# 今日三件事 (Today's Three Things)

一个轻量、纯粹、聚焦关键的中文静态网页应用。每天聚焦完成最重要的三件事。

## 核心特性

- **要事优先**：每日最多添加 3 件要做的事，空内容或纯空格自动拦截并提示。
- **满额友好提醒**：达到 3 件后，点击添加或回车均会在页面内给出清晰提示，输入框保持可用。
- **状态管理**：可自由勾选完成或取消完成，支持随时删除不需要的事项。
- **实时统计**：实时显示“已完成 X 件 / 共 Y 件”进度状态。
- **无障碍与全键盘支持**：
  - 支持 `Tab` / `Shift+Tab` 顺畅遍历所有交互控件。
  - 原生复选框，可直接用 `Space`（空格键）切换完成状态。
  - 输入框内按 `Enter` 快速添加。
  - 删除事项后自动将焦点平滑引导至临近事项或输入框，避免键盘用户失焦。
- **全端自适应**：精心设计的现代极简排版，在桌面宽屏与 375px 窄屏手机视口下均可舒适操作，长文本自动断行不溢出。

## 使用方式与打开方法

本应用为零依赖单文件纯静态网页，无需配置任何 Node.js、后端服务或外部网络连接：

1. **直接双击打开**：
   在文件管理器（如 macOS Finder 或 Windows 资源管理器）中直接双击 `index.html`。
2. **通过浏览器直接打开**：
   使用 Google Chrome、Edge、Safari 等主流现代浏览器，按 `Cmd+O`（或 `Ctrl+O`）选择 `index.html` 打开，即可通过 `file://` 协议本地运行。

## 快捷键说明

| 操作 | 快捷方式 |
| --- | --- |
| 聚焦输入框并提交 | 在输入框内输入文字后按 `Enter`（回车键） |
| 切换控件焦点 | 按 `Tab` 向后导航，`Shift + Tab` 向前导航 |
| 标记完成 / 取消完成 | 焦点落在复选框上时按 `Space`（空格键） |
| 删除当前事项 | 焦点落在“删除”按钮上时按 `Enter` 或 `Space` |

## 本地存储与使用限制说明

- **专属存储**：数据自动保存在当前浏览器的 `localStorage` 中（专属存储键 `wfweb001.todo.v1`），刷新页面后内容依然完整保留。
- **浏览器配置绑定**：数据保存在本地浏览器用户数据目录中。若更换其他浏览器、使用无痕/隐私窗口（Incognito）或清理浏览器缓存数据，事项数据将无法跨配置同步或可能被清空。
- **单机离线**：不设账号体系与云端同步，数据仅存放在您当前使用的本地设备上。
