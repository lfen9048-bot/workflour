# 视觉收尾

收尾是完成已选方向，不是暗中重做设计。先看已有设计约定、相邻页面、共享组件和 Plan 反馈；没有正式设计文档时沿用可确认的项目惯例，不强制另建一套设计系统。

只选择本次改动相关的部分，在已有浏览器验证中合并检查：

1. **完成路径**：先处理任务受阻、状态误导、错误恢复和不可访问，再处理视觉细节。加载、空数据、失败与成功状态按本功能实际需要补齐。
2. **层级与布局**：主要任务和当前状态明显；相关内容靠近，不同内容分开；同类字号、间距、对齐和控件与项目一致。实际长文本与窄屏不能遮挡操作。
3. **颜色与图形**：沿用语义颜色、图标家族和共享样式，检查文字、控件与焦点的可读性；保持图片比例，避免加载后布局跳动。只验证支持的主题。
4. **交互与文案**：标签说清动作，错误解释原因与下一步；键盘焦点、禁用和进行中状态准确。仅在有用途时增加动画，遵守减少动态效果偏好。不得为润色改变事实、承诺或任务范围。

在最小正确位置修复：能用已有组件或 token 就复用，局部例外不必抽成新系统。小修复检查原问题及受影响路径；新页面走完整约定路径并查看实际桌面、窄屏截图。复用仍有效证据，源码测试或自动扫描通过不能代替看图和操作。

交付前核对差异，移除本次引入的临时代码、无用样式和意外改动；记录剩余缺口并交回既有审核流程。主编码的收尾不能代替独立技术审核或 Plan 体验检查，不自行追加评审轮次。
