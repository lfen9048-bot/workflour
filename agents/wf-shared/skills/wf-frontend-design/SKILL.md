# Frontend Design · Workflour

先认清页面用途和用户动作。已有产品细化保留其视觉语言，新页面根据题材选择清楚的排版、色彩与视觉重点。不能把美学偏好加成用户限制；不要自动要求离线、SVG、自造插画或特定框架。

用短小的设计说明确定布局、字级、间距、颜色和一处重点；立即做关键页面可运行版本，交 Plan 评审观察方向后继续。实现键盘焦点、可读对比、合理触控尺寸、窄屏布局和减少动态效果偏好。文案以用户操作命名，空状态和错误解释下一步。

真实渲染桌面与手机，检查文字截断、溢出、主路径与状态反馈。截图必须读图后才评价视觉；仅保存图片不算已看见。对普通操作工作台优先清楚和克制，不强加展示页装饰。
