# Frontend Design · Workflour

先认清页面用途和用户动作。已有产品细化保留其视觉语言，新页面根据题材选择清楚的排版、色彩与视觉重点。不能把美学偏好加成用户限制；不要自动要求离线、SVG、自造插画或特定框架。

新页面或重要方向变更，用短小的设计说明确定布局、字级、间距、颜色和一处重点；先做关键页面可运行版本，按既有流程交 Plan 评审观察方向后继续。局部修复沿用已认可设计，不自动开启新预览或重新设计。实现键盘焦点、可读对比、合理触控尺寸、窄屏布局和减少动态效果偏好。文案以用户操作命名，空状态和错误解释下一步。

实现完成或有具体视觉修复时，按需读 [视觉收尾](references/visual-finish.md)。复用 [wf-webapp-testing](../wf-webapp-testing/SKILL.md) 的真实操作与读图证据，在约定桌面和手机视口检查受影响路径；仅保存图片不算已看见。对普通操作工作台优先清楚和克制，不强加展示页装饰。
