# Receiving Code Review · Workflour

先读全部审核意见，再逐项核对实际代码、复现步骤、用户约束和影响范围。确认的缺陷修复；不成立的意见用代码或运行证据回应。避免仅口头接受或盲目照改。

问题含糊时只暂停依赖该问题的部分，继续独立且清楚的修复。把技术问题与产品体验问题合并成一批返工，使用 Plan 负责人分配的共同两轮预算。回传“意见→处理→验证证据”，标明未解决项。通过原生派单返回，不向祖先再次派单，不另开新账本；本技能不授权向 GitHub、邮件等对外发布。
