# Obsidian Markdown · Workflour

修改前先读知识库的记录约定和目标笔记。保留现有 frontmatter 与内部双链；笔记用 [[目录/笔记|显示名]]，外部网页用 Markdown 链接；图片可用 ![[附件路径]]。复杂语法按需读 [属性](references/PROPERTIES.md)、[嵌入](references/EMBEDS.md)、[提示块](references/CALLOUTS.md)。

记录用户决定、团队假设、已执行与已验证事实的区别，链接实际文件、测试输出和截图。重要进展更新项目首页，日常碎片不堆长日志。不改观察器自动维护区的手写以外内容，不把历史建议覆盖最新要求。不要记录密钥；文件已生成不宣称已在 Obsidian 可视检查。

来源与改动见 [SOURCE.md](SOURCE.md)。
