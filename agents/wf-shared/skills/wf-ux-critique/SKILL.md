# UX Critique · Workflour

先确认本次验收目标、用户和当前阶段。只读对应参考，不把每次评审变成完整审计：

| 当前材料或任务 | 读取 |
|---|---|
| 初案，尚无可操作页面 | [初案检查](references/plan.md) |
| 可运行关键页面，确认方向 | [关键预览](references/preview.md) |
| 正式实现，检查真实用户体验 | [最终体验](references/experience.md) |
| 已有问题修复后的复审 | [局部复审](references/recheck.md) |

用验收要求、实际使用路径和证据判断，不把个人风格偏好升格为缺陷。区分已观察、推测和未验证；截图需实际读图，自动扫描通过不能证明体验通过。

只向当前负责人交回结论与问题，不启动子 Agent、不另建评审流程、不更新共享账本。沿用团队返工轮次和停止条件；材料不足时报告具体缺口，不默认追问用户或扩大测试。技术实现合格不等于用户已验收。
