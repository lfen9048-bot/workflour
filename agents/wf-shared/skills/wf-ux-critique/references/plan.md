# 初案检查

以当前需求与验收条件为界，选择一个主要用户及其真实任务。沿着“进入页面 → 找到动作 → 完成任务 → 知道结果”阅读方案，找影响成功的缺口：

- 主要动作、当前状态和下一步是否清楚；是否要求用户记住上一页的信息或猜内部术语。
- 信息分组和操作次序是否匹配任务；必要的返回、取消或错误恢复是否有安排。
- 哪些空数据、失败、权限或长文本状态确实可能出现，方案是否处理；不为假设中的平台或角色扩充范围。
- 重要交互是否需要关键页面验证，哪些可以沿用已有组件与已认可设计。

交回可执行的方案意见：指出会阻碍目标的缺口、理由和最小调整；无关键问题则说明可以进入实现。尚未运行的行为标为待验证，不凭文字方案宣称可用、易用或视觉通过。不要求额外评分、完整画像或新审批。
