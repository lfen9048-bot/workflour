# Ubuntu 七Bot部署：验证与已知限制

本页记录2026-11-12移植范围。目标是Ubuntu24.04桌面x86_64；原Mac服务和正在进行的阅读清单演练没有作为本次部署目标被重启或迁移。

## 已实现的部署内容

- 本机固定工具安装、DSH Web账号源、六个DSH角色和Antigravity接入。
- repo相对角色路径、启动时私有插件路径、本机全新七角色ID、职责与模型分开。
- 真实模型目录预检、幂等创建、忙碌保护、保留其他Bot及手选模型。
- 精简工作台独立副本、systemd用户后台、每20秒只读记录、北京时间13点签到与恢复检查。
- 本机Obsidian入口与记录规则；不覆盖原笔记，不复制Mac私密数据。

## 本次检查记录

发布前将实际本地测试和Ubuntu Actions结果补记于此；没有目标机账号，不能执行用户虚拟机的模型调用或业务验收。

Linux自动检查不带凭据、不发送模型请求。它应覆盖全新工具安装、私有工作台真实HTTP响应、隔离Chrome截图、systemd语法及关键回归；测试用合成配置不能证明账号池中的账号可用。

## 必须在你的虚拟机确认

1. WorkBuddy登录、真实模型目录、剩余额度和具体图片输入能力。
2. Antigravity官方CLI登录、桌面密钥环、Gemini订阅/模型/档位及ACP真实调用。
3. 原生七Bot委派与完整网页任务。每个阶段记录真实输出，停在待用户验收。
4. 登录/重启后systemd用户服务行为、实际13点触发及自动记录。虚拟机休眠/关闭期间不能持续运行。
5. 模型切换和权限界面。Full默认并不绕过原生新任务安全策略；缺能力必须明确失败。

## 继承的工作流缺陷

- 多Agent小任务仍可能明显慢于单Agent，暂无同题对照证明更优。
- 审核可能漏报，测试通过不代表没有缺陷；阅读清单演练曾需维护复核补充两项缺陷，本次没有把该演练冒称验收通过。
- 部分国际DeepSeek线路只收文本，自动省额度选择可能使体验读图受阻。必须按实际回执处理，不能改成文字检查就称视觉通过。
- Antigravity外部咨询回传后可能新开底层会话并重放可见历史，增加耗时；不承诺全部原生工具上下文无损延续。
- 自动记录是摘要和证据索引，不是会话备份恢复器。GitHub资料不能精确还原原Mac会话与派单链。
- 官方Antigravity安装器未在本仓库固定一个Linux二进制SHA；安装后应保存实际版本。其账号和模型可用性不能由无账号CI证明。

未改变七角色默认模型、长期额度排序、技能启用门槛、返工预算或用户验收职责。本次只补目标平台部署能力。
