## 第一项网页业务演练

由使用者在**大管家新对话**发：

> 在 C:\workflour-projects\windows-plan-code-demo 新建“每日三件事”中文网页。最多保存三件事，可完成、删除、只看未完成；刷新仍保留。满额提示清楚，切换筛选和删除后剩余数量正确，键盘也能操作，电脑和手机都好用。请让Plan研究并评审方案，Gemini主编码、独立技术审核、Plan实际体验，最后给我入口和验收说明，停在待我验收。目录和命令由团队完成。

不要复制历史产品后称新任务已实现。普通任务先仅一名主编码；是否启用helper必须有明确独立范围。验证新增、满额、完成/删除、筛选、刷新、键盘焦点、窄屏布局和数据错误处理。保存桌面/手机截图并读图，不能只有DOM断言。必要返工保留轮次；断言依据用户行为和明确fixture。

部署Agent可以观察与维护，不直接分别向成员代发业务任务后声称自动链路通过。维护介入写时间、原因和影响；最后应是Plan通过原派单回传大管家。验收仍由用户。

CLI项目可额外演练，但负责人要设`product_surface:cli`并记录真实命令、退出码和逐目标操作；CLI证据不能替代本网页验收。

## 测试顺序

先查看相关测试依赖，适配后按功能运行：账本/恢复/supplements、模型控制、额度策略/路由、签到、profile/pool同步、观察器、UI。Mac launchd测试可标平台限定，但Windows要有对应功能证明，不能全量skip。

```powershell
py -3 -m unittest discover -s tests -p 'test_*.py' -v
if ($LASTEXITCODE -ne 0) { throw 'Python tests failed' }
Get-ChildItem tests/test_*.mjs | ForEach-Object {
  node --test $_.FullName
  if ($LASTEXITCODE -ne 0) { throw "Node test failed: $($_.Name)" }
}
```

这是完成依赖适配后的整体检查示例，不是未经阅读就运行所有旧Mac探针。真实模型调用用最小请求，不故意用完余额。合成QUOTA仅装临时隔离profile；不要留在正式入口。产品测试通过项目checker保留原命令、真实退出码和输出，不用管道成功码替代。

## 故障分类

| 现象 | 查哪里 | 不应怎么处理 |
| --- | --- | --- |
| 网页断开 | 浏览器到OMB、服务端时间/端口/归属 | 直接说GLM没额度 |
| 60秒未回复 | 原请求是否仍活跃、上游排队、工具执行 | 再派一份任务或直接API |
| 目录空/模型不存在 | profile、插件、区域、上游目录、enabledModelIds保留 | 根据旧缓存补造模型 |
| 国际旧0折 | 当前catalog倍率和促销有效期 | 把缓存免费当实际成功 |
| 价格/余额读失败 | 安全错误码、登录与网络 | 当额度用尽升级到付费 |
| QUOTA | 当前账号/模型、尝试清单、有效候选 | 修改所有Bot永久默认 |
| 429/队列/服务错误 | 原始分类、有界重试和允许账号 | 一概当余额不足 |
| 登录失效/加密凭据 | 同用户、插件doctor摘要、WorkBuddy exe位置 | 复制Mac token/公开原始诊断 |
| ACP解析错误 | stdout日志/BOM、`.cmd`、字节流 | 忽略后创建空会话 |
| fcntl/O_NOFOLLOW/Ruby不存在 | 启动器、checkin、bridge、项目复制checker | 删除锁/改成永远成功 |
| 终端能用后台不能 | PATH/绝对程序/cwd/登录用户/环境 | 连续重装掩盖问题 |
| supplement未结束却复审 | 原生queued回执、登记和最新报告 | 只看主单completed |
| 签到超时 | 当日读回、unconfirmed、上次claim记录 | 自动重复领取或报成功 |
| skills只有一行文本 | Windows symlink和Git检出行为 | 当成已加载完整技能 |
| UI没变/切页异常 | 源版本哈希、私有runtime链接/复制、CSS/JS载入 | 改全局包凑效果 |
| Obsidian/分类不更新 | register、vault、observer、desktop队列与真实cwd | 直接改数据库或生成页掩盖 |
| 重启不见记录 | Windows用户、DSH_HOME/OMB根、原ID与回执 | 清账本重新叙述当恢复 |
