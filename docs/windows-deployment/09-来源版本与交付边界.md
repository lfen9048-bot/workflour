## 仓库做了什么与没做什么

提供重要源码、角色技能及许可证、模板、测试、当前大纲、工作记录与Windows步骤；排除凭据、原生运行数据库、账号目录、原始聊天镜像和不应公开的运行材料。以实际仓库树及发布清单为准，不引用旧ZIP文件数当新仓库完整性证明。

没有在目标Windows登录、没有执行Windows安装、没有完成Windows启动器/文件锁/签到适配或Windows端到端验收。Mac配置、Bot ID、计划任务与会话链不能照搬。Git仓库是学习和部署起点，不是应用状态备份。

- 新项目plan-code全流程、补充回执、停止续跑及真实故障的Windows证据。

## 遇到冲突时

优先当前用户明确指令和最新有效决定；再读当前架构、状态、角色及源码核实。本组Windows步骤据此实施，历史记录只解释过程。计划、实施、验证各自标记；官方支持Windows不等于本项目所有脚本已支持Windows。
