## 主要结论

配置独立的 Harness 多进程具有实现依据；仅换 profile 或仅换 `DSH_HOME` 不足以承诺全部隔离。WorkBuddy 插件自有数据可按 root 分开，但桌面账号发现与上游额度仍可能共享。OS 文件访问隔离需要额外边界。

完整依据、版本差异和待验证项见 [02-调研/2026-11-05-现有工具与Harness多实例隔离](../02-%E8%B0%83%E7%A0%94/2026-11-05-%E7%8E%B0%E6%9C%89%E5%B7%A5%E5%85%B7%E4%B8%8EHarness%E5%A4%9A%E5%AE%9E%E4%BE%8B%E9%9A%94%E7%A6%BB.md)。
