# 建立项目接手入口

## 本次目的

把用户认可的项目接手说明写入当前项目，连接项目实际产物与 Obsidian 中的共同工作记录。

## 本次明确的约定

用户确认按上一轮草稿建立项目 `AGENTS.md`，并明确有实质进展时再更新 Obsidian。具体决定见 [06-决策/0001-项目入口与上下文记录约定](../06-%E5%86%B3%E7%AD%96/0001-%E9%A1%B9%E7%9B%AE%E5%85%A5%E5%8F%A3%E4%B8%8E%E4%B8%8A%E4%B8%8B%E6%96%87%E8%AE%B0%E5%BD%95%E7%BA%A6%E5%AE%9A.md)。

## 实际操作

1. 核对当前工作目录为 `<WORKFLOUR_ROOT>`，确认尚无 `AGENTS.md`。
2. 阅读知识库首页、需求页、记录约定和知识库自身的 `AGENTS.md`。
3. 在项目根目录写入用户确认的接手说明，记录知识库绝对路径、阅读顺序、工作规则和记录维护方式。
4. 记录本次共同决定，更新需求页、记录约定、知识库自身的 `AGENTS.md` 和首页交接，统一“有实质进展时更新”的频率。
