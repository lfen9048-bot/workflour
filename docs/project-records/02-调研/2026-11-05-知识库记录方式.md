# 知识库记录方式

查阅日期：2026-11-05。

本次只检索如何建立可持续的搭建记录，不进行多 Agent 编码框架选型。

- 本机已安装 Obsidian。
- 当前工作目录未找到可直接复用的 README、AGENTS.md 或记录模板文件（检查范围为相关文件名）。

## 实际阅读的来源

### Obsidian 官方：数据存储

[How Obsidian stores data](https://help.obsidian.md/Files+and+folders/How+Obsidian+stores+data)

官方说明知识库是本地目录，笔记是 Markdown 文本，独立配置位于 `.obsidian/`。因此可以先生成可直接编辑的笔记目录。

### Obsidian 官方：模板

[Templates](https://help.obsidian.md/Plugins/Templates)

内置 Templates 能插入模板，并替换标题、日期等变量。本次使用普通 Markdown 模板，复制即可使用，不依赖社区插件。

### 现成项目记录模板

[Obsidian Project Vault Template](https://github.com/BrineWR71/obsidian-project-vault-template)

已阅读实际 README。它提供项目入口、会话日志、决策记录、会话交接和模板，README 标注 MIT，且声明无需必装插件。

适配判断：采用它的浅层目录、日志、决策和交接思路；其完整的领域、资源和产品分类对当前单一搭建任务偏多。本次用原创中文笔记和精简目录实现，未复制或安装其代码、技能、插件。

维护核对：本次阅读了 README；未进一步核对提交历史、发布记录和依赖兼容性。由于不引入该项目的代码和运行依赖，这些字段留存为未核实。
