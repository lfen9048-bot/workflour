# Harness 社区分支和扩展候选

## 调研背景

用户提到网上见过“分割 DeepSeek Harness 版本”的开源项目，但无法提供名字或链接。本次按 fork/社区改版、桌面工作台、发行配置层和多 Agent 插件检索。以下是实际找到并阅读文档的候选，不能认定其中某个就是用户看到的项目，也没有选择迁移。

## 候选与准确定位

### Minke：基于 Harness 的桌面工作台

[仓库与实际 README](https://github.com/lencx/Minke)

把对话、文件、终端与共享浏览器放到同一工作区，支持分屏、文档预览、修改审阅、模型服务和 DSH skills/子 Agent/插件。偏重新组织桌面工作体验，并非仅给官方页面加安装壳。

README 当前源码使用 DSH 0.2.1-rc.2，与本机相近，但发布包可能不同。仓库未归档，最近提交 2026-10-18；GitHub 元数据标注 Apache-2.0。已有 WorkBuddy 插件、历史和模型/skills 配置能否直接迁移未实测。

### DSH Tauri 桌面版：桌面与档案管理

[仓库与实际 README](https://github.com/dsh-tauri/deepseek-harness-desktop)

提供内核版本、插件、档案与数据目录管理，档案支持备份、克隆、迁移，也有会话级 worktree、远程与移动端功能。这里的档案管理不等同于已经实现“独立模型/skills、所有记录统一汇总”的特定组合。

README 推荐内核 0.2.1-rc.4，最低支持也是该版本，不能直接假定适配本机 0.2.1-rc.2。仓库未归档，2026-11-06 有提交。

许可并非只看 MIT 徽章：实际 [LICENSE.details](https://github.com/dsh-tauri/deepseek-harness-desktop/blob/main/LICENSE.details) 另附禁止商业二次开发条款，原文同时允许直接商业使用。本次没有作进一步许可解释。

### DeepSeek Harness Community：明确的社区 fork

[仓库与实际 README](https://github.com/samuelrubiodev/deepseek-harness-community)

主要面向 Docker、NAS、服务器、局域网/反向代理部署，提供多架构预构建镜像、内部预览代理与浏览器组件。Agent loop、插件和会话存储沿用上游，不是以新增每 Agent 独立模型/skills 和统一协作工作台为主要功能。

当前 CLI 包为 0.2.1-rc.3；MIT，未归档，最近提交 2026-11-01。当前用户是本机桌面工作流，除非新增服务器/NAS需求，否则它不能直接取代现有分工配置。

### MoA+ / Project Mode：多 Agent 项目协作扩展

[仓库与实际 README](https://github.com/Burns1028/moa-plus)，旧地址 `Burns1028/dsh-plugin-project-mode` 重定向至此。

常驻 Coordinator 统筹可复用 Workers，维护共享项目记忆、跟进任务、自动回传结果；可在原生侧边栏打开 Worker 历史并直接指导。演示任务正是一个 Worker 改代码和测试、另一个维护文档。

这是插件加兼容运行环境，不是独立重写的 Harness。v0.1.23 要求 DSH 0.2.1-rc.3 加三项兼容扩展，原版 rc.3 也不能直接启用；自带隔离 setup 不复用现有 Desktop 和 `~/.dsh`。[兼容说明](https://github.com/Burns1028/moa-plus/blob/main/docs/compatibility.md)

Worker 创建接口未提供独立 model/skills 参数，不能直接承诺复用现有两个 CLI 的不同配置。[Worker 实现](https://github.com/Burns1028/moa-plus/blob/main/packages/project-mode/src/host/worker-operations.ts)

MIT，未归档，最近提交 2026-11-05。编排方向与代码加文档目标接近，但具体模型/skills 与 WorkBuddy 兼容需另验。

## 其他确有其项目的线索

- [DSH Desktop by Dataelem](https://github.com/dataelement/dsh-desktop)：已读 README。桌面发行版，增加可导入导出的 Agent preset、PPTX/Office 能力、手机访问与恢复功能；main 基于 0.2.2-alpha.2，MIT，最近提交 2026-11-04。与官方桌面不同的数据位置和插件兼容仍需实测。
- [amplifthq/oh-my-dsh](https://github.com/amplifthq/oh-my-dsh)：README 明确 Overlay, not a fork，是配置/发行层，提供 Web/headless、LSP、MCP、用量和第二模型顾问等能力。当前 v0.1.7 固定上游 0.1.0-rc.8，MIT，最近提交 2026-10-17。同名项目很多，不能只凭 oh-my-dsh 名称认定仓库。

## 与本项目的关系

- 若关注桌面文件、终端、文档和分屏工作区，Minke 更对应这一类需求。
- 若关注常驻总协调者与多个长期 Worker，MoA+ / Project Mode 更对应这一类需求。
- 若关注多档案和运行时管理，DSH Tauri 属于相关桌面候选。
- 若关注服务器/NAS常驻部署，Community fork 更对应这一类需求。

以上只是按功能归类，尚未推荐立即替换现有系统。所有候选的模型服务仍使用相应账号/额度；没有据开源许可推定模型调用免费或 WorkBuddy 自动兼容。

## 实际操作边界

本次仅检索、读取 README/许可/元数据与必要实现。未安装、启动、调用模型、改动现有代码或迁移历史。目标项目仍未确定。
