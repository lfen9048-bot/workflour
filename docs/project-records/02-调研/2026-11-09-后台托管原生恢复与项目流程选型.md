# 后台托管、原生恢复与项目协作流程选型

用户授权先解决后台启动与重启交接，再搭完整项目协作流程。按search-first检查已有脚本、技能、运行时源码，再检索GitHub/官方文档并实际验证候选。

## 后台托管

采用macOS用户级launchd，复用本机OpenMausBot 0.1.143服务生成器，补自建public-url，并单独管理SSH。PM2多一层依赖且macOS仍依赖launchd；Homebrew services需额外formula，对当前两个进程收益小。系统方案无新增包、账号或费用。

实际阅读：[Apple服务文档](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html)、本机man launchctl/launchd.plist、[Apple man源码](https://github.com/apple-oss-distributions/launchd/blob/main/man/launchd.plist.5)、[PM2 startup](https://pm2.keymetrics.io/docs/usage/startup/)、[PM2 AGPL许可](https://github.com/Unitech/pm2/blob/master/GNU-AGPL-3.0.txt)、[brew services](https://docs.brew.sh/Manpage#services-subcommand)与BSD许可。两候选活跃维护但增加配置；未复制候选代码。当前OpenMausBot发行包Apache-2.0，仅导入现有生成器。

## Harness恢复

本机DSH rc.2真实实现session/resume，调用agents.resume恢复持久Agent；OMB通用customAcp却调用session/load，失败时只用聊天文字重建。内置deepseek驱动已有resume但会改变profile/认证接入，因此不直接切换。项目内标准库薄桥只改这个method，ID/params/输出不变，不改npm安装包，不宣称标准load历史重放。

已读：[官方ACP README](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/acp/acp/README.md)、[实现](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/acp/acp/src/index.ts)、[现成讨论6393](https://github.com/deepseek-ai/deepseek-harness/discussions/6393)及本机打包源码。Harness MIT；桥接自行实现、零第三方包。升级任一产品要复验。

## 完整协作流程

采用GitHub Spec Kit固定v1.3.2/55264c2f2f2d1146f02abc543cb913dcdf1f9342的none中立集成。官方现已支持dsh/agy，但自动dispatch使用另外的headless入口，会绕开现有ACP profiles；默认skills发现也与当前includeDefaultRoots:false不兼容。none只生成共享材料，保持角色配置。

实际隔离验证none/dsh/agy初始化成功；none20文件，另两者29文件。官方feature/plan/tasks材料脚本实际可运行，缺tasks会被prerequisites拒绝。复用20个中立文件、MIT许可和源文件哈希；用项目内小检查器补独立审查、真实测试记录和快照失效检查，不引入通用自动调度。

来源：[Spec Kit README](https://github.com/github/spec-kit)、[固定版本](https://github.com/github/spec-kit/releases/tag/v1.3.2)、[MIT许可](https://github.com/github/spec-kit/blob/v1.3.2/LICENSE)、[none](https://github.github.io/spec-kit/integrations/none.html)、[dsh](https://github.github.io/spec-kit/integrations/dsh.html)、[agy](https://github.github.io/spec-kit/integrations/agy.html)、[实际模板](https://github.com/github/spec-kit/tree/v1.3.2/templates)。Spec Kit持续发布，无额外付费服务；本机已具备Python/uv。固定副本可离线初始化，不要求用户安装新的全局CLI。

另读BMAD实际README/MIT许可，角色体系迁移量较大，本轮不整套引入；GSD旧库已归档，新Core的STATE/验证产物可借鉴，但自动子Agent并行流程不直接替代当前手动接力。
