## 3. Skills 结论的边界

自动注入的技能清单确实分别只有 `code-assistant` 或 `doc-writer`，因此“自动发现/加载清单分开”通过。

但 Doc 的 `session-LOCAL-ID-023` 在列技能时主动通过 shell 列举并读取了 `~/.dsh/skills/*/SKILL.md`。桌面实际显示的最终回答为“7 个”技能，包含 doc-writer 和六个全局技能。它没有自动注入这些全局技能，却可以通过普通文件工具发现并读取它们。

因此应表述为：**skills 自动清单分离已通过；没有形成禁止读取其他 skills 文件的权限隔离**。用户当前最小目标的基础配置已落地，本轮不追加权限隔离实现，也不改动任何配置。

- “列出当前自定义技能清单”：显示 code-assistant，模型选择为 GLM-5.3-Flash，任务已完成。
- “列出自定义技能及描述”：显示上述 7 项回答，模型选择为 DeepSeek-V4.1-Flash，任务已完成。

同时可见两条自我介绍测试历史。由此确认 CLI 历史可以在同一桌面读取。它们当前显示于“未分组”，本次未看到独立 workflour 工作区分组。磁盘目录按 cwd 命名，不代表桌面工作区已经自动建立或归组。
